# Changelog

All notable changes follow Semantic Versioning.

## [1.0.0] - 2026-06-13

### Added

- User-triggered current-viewport runtime evidence capture.
- Multi-viewport sessions, bounded element collection, and structured diagnostics.
- Optional visible-viewport screenshot capture with explicit consent.
- Deterministic local ZIP packaging with SHA-256 checksums.
- Chrome and Edge production manifests plus an experimental Firefox event-page manifest.
- English and Persian localization, RTL support, and keyboard-accessible interfaces.
