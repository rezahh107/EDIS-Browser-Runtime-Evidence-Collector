# Privacy Policy

EDIS Browser Runtime Evidence Collector operates locally. It has no telemetry, analytics, advertising, tracking, remote API, automatic upload, browsing-history collection, cookie access, or form-value access.

Capture starts only after a user action. By default the extension records normalized origin, viewport and document dimensions, bounded element geometry, allowlisted computed-style strings, identity markers, and structured diagnostics. URL query strings and fragments are removed. Full text and screenshots are disabled by default and require explicit opt-in.

Preferences use browser synchronization storage only for small non-sensitive settings. Session coordination uses session storage. Snapshots, chunks, and optional screenshots use extension-scoped IndexedDB. After a successful export initiation, large session artifacts are deleted unless retention is enabled. The options page provides a clear-all-data action.

The export review identifies enabled categories before local download. Exported packages remain under the user's control.
