# Version 1.6.20

This maintenance release improves runtime-evidence correctness and release verification without expanding permissions or adding remote services.

- Improves rendered visibility and viewport-image readiness measurement.
- Makes exported session evidence non-destructive until the user explicitly clears extension data.
- Tightens package inventory validation and source/release provenance checks.
- Requires exact Chrome Stable and Microsoft Edge Stable qualification before trusted release packaging.

Runtime Snapshot schema remains compatible at `1.6.0`.
