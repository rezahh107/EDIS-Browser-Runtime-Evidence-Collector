# Release notes — 1.2.0

- Hardened deterministic identifiers, canonical serialization, hashing, ZIP generation, and reproducible builds.
- Strengthened message correlation, sender validation, chunk validation, cancellation, navigation handling, and IndexedDB recovery.
- Added bounded text-layout evidence and an optional, disabled-by-default redacted text preview.
- Added a real-browser Playwright harness for extension loading, capture, determinism, recovery, privacy, network isolation, export, and accessibility verification.
- Added release-gate automation, manual compatibility templates, and Chrome Web Store submission materials.

No telemetry, analytics, remote API, automatic upload, page modification, UX scoring, or accessibility verdicts were added.
