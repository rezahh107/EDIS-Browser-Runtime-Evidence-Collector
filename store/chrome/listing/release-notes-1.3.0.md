- Added a complete bundled Persian and English user guide.
- Added bounded Standard, Deep DOM, and Custom capture profiles.
- Added exact capture-completeness and truncation evidence.

- Unified browser metadata across session, page, and snapshot artifacts.
- Advanced the evidence schema to version 1.1.0 independently of the extension version.
