- Added evidence lineage from rendered page and observation to preliminary source document, section, element, and runtime node evidence.
- Added rendered-page/source-document separation, multi-document binding, runtime structural regions, and deterministic page structure summaries.

No telemetry, analytics, remote API, automatic upload, UX scoring, final correlation, source-value resolution, or recommendation generation was added.
