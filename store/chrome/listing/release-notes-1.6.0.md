# Release notes — 1.6.0

- Prunes hidden descendant subtrees when hidden collection is disabled and exports transparent skipped-subtree counts.
- Uses viewport-aware image readiness and separates total from visible incomplete images.
- Adds discovered/emitted metric scopes, capture-state/environment facts, runtime/document instances, and source/runtime cardinality evidence.
- Adds strict schema-index validation, removes duplicated diagnostic storage, and advances Runtime Snapshot/Package Schema to 1.4.0.
- Shows the installed manifest version at the top of the popup and side panel.
