# Asset checklist

- [ ] Final production icon visually reviewed at all bundled sizes.
- [ ] Required store screenshots captured from the final build.
- [ ] Screenshot dimensions accepted by the current dashboard.
- [ ] No passwords, tokens, email addresses, private page content, or confidential screenshots.
- [ ] English interface represented accurately.
- [ ] Persian/RTL interface represented accurately when listed.
- [ ] Optional screenshot and text preview defaults shown accurately.
- [ ] No unsupported claims or approval badges.
- [ ] Promotional assets exported if required.
- [ ] Asset SHA-256 inventory recorded.
- [ ] Accessibility of embedded text and contrast manually reviewed.
