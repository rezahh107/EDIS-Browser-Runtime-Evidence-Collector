# Promotional assets specification

Prepare assets from the final brand source using the current Chrome Web Store requirements shown in the dashboard at submission time.

- Store icon derived from the bundled extension icon, with no misleading badges.
- Small promotional tile when requested by the dashboard.
- Marquee or additional promotional image only when required or intentionally supplied.
- Screenshots of the actual extension, not conceptual renderings.
- No browser, Google, Chrome, Elementor, or accessibility certification claims.
- No confidential evidence or third-party trademarks used without authorization.

Record source file, dimensions, export settings, reviewer, and SHA-256 for each final asset.
