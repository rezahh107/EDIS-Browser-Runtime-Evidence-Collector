## Install and exercise

1. Load the submitted Manifest V3 package.
2. Open an ordinary HTTP or HTTPS test page.
3. Click the extension action to open the popup.
4. Open the side panel when offered.
5. Create a session and select **Capture current viewport**.
6. Review the local snapshot count and diagnostics.
7. Export the evidence ZIP.
8. Open Options to inspect default privacy settings and the clear-data action.

No account, API key, server, or network connection is required for extension functionality. Screenshots and text preview are disabled by default.
