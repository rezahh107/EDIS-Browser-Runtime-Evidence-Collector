# Data-use declaration

## Used data categories

The extension may process page origin, optional normalized path and title, viewport and document metrics, bounded DOM identity metadata, geometry, allowlisted computed styles, visibility and overflow facts, diagnostics, and optional user-enabled screenshot or bounded text preview.

## Prohibited or excluded data

The extension does not read or export cookies, browsing history, other sites' storage, form values, password values, hidden field values, clipboard contents, keystrokes, URL credentials, query strings, fragments, or authentication tokens.

## Purpose limitation

All collected evidence is used only to create a local, versioned evidence package for offline EDIS analysis. It is not used for advertising, personalization, creditworthiness, lending, insurance, employment, or unrelated profiling.

## Transfer and sale

No data is sold. No telemetry, analytics, remote API, automatic upload, or third-party transfer is implemented.
