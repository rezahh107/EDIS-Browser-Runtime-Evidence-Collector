# Field-Level Privacy Inventory

Required fields include schema metadata, timestamps, collector identity, actual viewport dimensions, document dimensions, bounded element identities, finite geometry, raw allowlisted styles, evidence flags, and diagnostics.

Optional fields include normalized path, title, accessibility metadata presence, colors, limited text preview, screenshot bytes, WordPress bundle reference, document reference, and site fingerprint. Optional privacy-sensitive categories are surfaced in review.

Forbidden fields include cookies, storage contents, URL query and fragment, credentials, form values, hidden values, password values, authentication tokens, credit-card values, private messages from contenteditable controls, history, and keystrokes.
