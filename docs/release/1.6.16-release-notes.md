## Scope

This release repairs the release pipeline without changing Browser evidence behavior. The no-browser gate now starts from clean evidence state and executes the real repository test runner before validating its reports. Final Chrome and Edge ZIPs are rebuilt from the same final source state included in the deterministic source ZIP.

## Release-integrity controls

- Every external GitHub Action is pinned to a full 40-character commit SHA.
- A workflow policy gate rejects rolling tags and branches.
- A deterministic source package is generated from `GENERATION_MANIFEST.json`.
- The provenance gate extracts that source package, rebuilds both browser targets, and requires the rebuilt ZIP bytes to equal the shipped ZIP bytes.
- Release evidence separates repository/build integrity from browser-runtime qualification.

## Runtime qualification

No unavailable browser execution is converted to `PASS`. Automated Playwright Chromium and exact Chrome/Edge qualification remain separate evidence scopes. Exact runtime status for this delivery is recorded in the test-results document.
