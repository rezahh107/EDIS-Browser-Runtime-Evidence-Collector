## Implemented changes

1. Added one shared, deterministic Elementor runtime-marker classifier used by both bounded discovery and emitted-element metrics.
2. Added explicit `skipped_elementor_elements` evidence and the invariant `discovered = emitted + skipped`.
3. Added fail-closed validation code `EDIS_RUNTIME_ELEMENTOR_METRIC_INVARIANT_VIOLATION` for contradictory metric relationships.
4. Added package and external-validator checks for duplicate/non-contiguous observation indexes and missing/orphan snapshot references.
5. Preserved same-tab and same-session capture exclusion and transactional finalization hardening from 1.6.4–1.6.5.
6. Advanced Runtime Snapshot and Runtime Package schemas to patch version `1.4.1`; no analytical ownership moved into Browser.

## Architectural boundary

The Browser Collector records observable runtime markers, geometry, styles, relationships, readiness, capture environment, and preliminary source-binding evidence only. It does not resolve Elementor source identity, Variables, Classes, breakpoints, formulas, UX findings, final correlation, or TruthReport results. Those remain Python-owned.
