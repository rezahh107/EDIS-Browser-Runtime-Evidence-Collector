```yaml
extension_version: 1.6.14

permission_change: false
network_change: false
indexeddb_version: 4
```

## هدف

نسخهٔ 1.6.14 همهٔ ۱۲ یافتهٔ گزارش ممیزی عملکرد 1.6.13 را به تغییرات اجرایی کم‌ریسک تبدیل می‌کند. این نسخه هیچ Fact جدیدی نمی‌سازد، Schemaهای شواهد را تغییر نمی‌دهد و مسئولیت Resolution، Formula، Rule، Correlation و TruthReport را از Python نمی‌گیرد.

## اصلاحات اصلی

- Text Shape فقط زیر‌درخت عناصر منتخب را می‌پیماید و دارای سقف سراسری برای TextNode، نویسه و ancestor step است. عبور از سقف با Diagnostic موجود و وضعیت `PARTIAL / BOUNDED_LIMIT_REACHED` ثبت می‌شود.
- sibling index و `nth-of-type` برای هر Parent در یک عبور و داخل Context همان Capture ساخته می‌شوند.
- اندازهٔ Canonical Snapshot و Screenshot هر Capture در metadata داخلی ثبت می‌شود. Capture و Export پیش از عبور از بودجهٔ تجمعی Session fail-fast می‌شوند.
- Screenshotهای Session با index جدید `sessionId` و یک Query گروهی خوانده می‌شوند.
- Maintenance سراسری IndexedDB حداکثر یک‌بار در بازهٔ نسخه‌بندی‌شده اجرا می‌شود و Recovery فقط Jobهای فعال را از index وضعیت می‌خواند.
- Snapshot assembly هر Chunk را یک‌بار Encode می‌کند و Referenceهای حجیم پس از استفاده آزاد می‌شوند.
- Hash و Screenshot storage کپی‌های غیرضروری TypedArray را حذف می‌کنند.
- ZIP reader از View بدون کپی استفاده می‌کند و Package Builder indexهای Map/Set و Canonical keyهای cache‌شده دارد.
- Readiness تصاویر Mutationهای مرتبط را افزایشی پردازش می‌کند و Full scan فقط در شروع Session رخ می‌دهد.
- `STATE_GET` خلاصهٔ سبک Sessionها را همراه فقط Session انتخاب‌شده بازمی‌گرداند.

## سازگاری

- Runtime Snapshot Schema: `1.6.0`
- Capture Session Schema: `1.1.0`
- Runtime Package Manifest Schema: `1.4.1`
- Chrome/Edge permissions: بدون تغییر
- Package paths و Canonical JSON: بدون تغییر
- IndexedDB: ارتقا خودکار از نسخه‌های قبلی به `4`; مهاجرت دستی لازم نیست

## محدودیت صریح

ZIP32 همچنان برای Blob نهایی به یک Buffer پیوسته نیاز دارد و CRC تمام Entryها را بررسی می‌کند. این هزینه اکنون با بودجهٔ تجمعی Session و سقف Package محدود است، اما Stream-to-download در قرارداد فعلی پیاده‌سازی نشده است.
