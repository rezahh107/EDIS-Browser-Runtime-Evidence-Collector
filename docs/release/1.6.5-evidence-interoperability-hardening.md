## Implemented changes

1. The diagnostics artifact now declares the same canonical schema ID as `diagnostics-artifact.schema.json` and `schema-index.json`.
2. Every emitted artifact is independently resolved by `schema_id` through the embedded schema index.
3. `coverage/evidence-coverage.json` reports evidence availability without scoring, correlation, resolution, or rule execution.
4. Export preflight displays observation, runtime-node, Source Context, viewport, screenshot, hidden-element, and incomplete-image coverage before download.
5. Same-tab and same-session active captures use stable diagnostic codes and remain fail-closed.
6. Optional lazy-load preparation performs a bounded sweep over the initial document height and restores the original scroll position.

## Architectural boundary

The Browser Collector still records runtime facts and preliminary binding evidence only. Python retains ownership of final correlation, resolution, formula/rule execution, diagnostics synthesis, and TruthReport generation.
